# دکمه تایید ساده

## توضیح
یک دکمه تایید ساده ساخته شده است که هیچ آیکونی ندارد و فقط متن "تایید" را نمایش می‌دهد.

## کامپوننت مورد استفاده
- **Button** از سیستم طراحی DIG

## ویژگی‌ها
- رنگ اولیه: `primary`
- حالت: `default` (توپر)
- اندازه: `default` (ارتفاع 9، پدینگ استاندارد)
- بدون آیکون
- رویداد click برای عملکرد تایید

## نحوه استفاده
```tsx
<Button onClick={handleConfirm}>تایید</Button>
```

می‌توانید واریانت، رنگ و اندازه را تغییر دهید و یک handleConfirm callback اضافه کنید.
